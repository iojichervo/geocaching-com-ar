# Geocaching Argentina (recreación)

Recreación estática del sitio geocaching.com.ar (hoy caído), reconstruida a partir de las copias de
[web.archive.org](https://web.archive.org/web/2022/http://geocaching.com.ar/).

- Sitio: https://iojichervo.github.io/geocaching-com-ar/
- `python3 tools/build.py` vuelve a descargar las páginas y los recursos desde el archivo y regenera el sitio.
- Algunos recursos nunca fueron archivados (p. ej. varias imágenes grandes y los PDF); formularios y búsqueda no funcionan.
